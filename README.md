# NovaCart - Professional E-commerce Website

This project is a multi-page e-commerce frontend built with **HTML**, **Tailwind CSS**, and **JavaScript**.

## Pages Included
- Home (`index.html`)
- Products (`products.html`)
- Cart (`cart.html`)
- About (`about.html`)
- Contact (`contact.html`)
- Login (`login.html`)

## Features
- Responsive navigation and layout
- Product listing with category filter and live search
- Add-to-cart functionality using browser localStorage
- Cart page with totals and remove items action
- Demo login and contact form handling

## Run locally
Open `index.html` in your browser.

For best results use a local server, e.g.:

```bash
python3 -m http.server 8000
```

Then browse: `http://localhost:8000`.
